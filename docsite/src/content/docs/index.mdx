## Genuinely open source

The server is AGPL-3.0, the agent is Apache-2.0, and contributions are
accepted under the Developer Certificate of Origin. There is no
source-available license waiting to close the door behind you. The
[licensing page](/concepts/licensing/) explains why the split.
